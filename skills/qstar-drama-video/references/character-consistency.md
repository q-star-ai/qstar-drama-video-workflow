# 人物连续性与 3D 预演

参考来源：[CozyClay 原项目](https://github.com/NomaDamas/CozyClay)、[项目许可说明](https://github.com/NomaDamas/CozyClay/blob/main/LICENSING.md)、[用户提供的 X 帖](https://x.com/AISuperDomain/status/2114327756532036045)。截至 2026-10-26，已核对 README 与许可；尚未在本项目中运行 CozyClay 或验证它与 H3 的成片效果。

CozyClay 的关键帧包可输出首尾帧、灰盒视频、镜头参数和提示词。我们将它作为可选预演步骤：先锁角色站位、动作和摄影机，再生成实际视频。它对空间、动作和机位有帮助，但灰盒人物不能代替客户批准的人脸和服装。

## 每镜输入

- 角色身份：已批准定妆照的私有资产 ID；同角色跨镜复用同一 ID。
- 服装：按剧情时间和场景指定的私有资产 ID；换装应是剧本事件，不是模型漂移。
- 场景：布局、光线与道具基准图的资产 ID。
- 预演：可选首帧、尾帧、灰盒片、摄影机参数。预演结果需人工审看，不自动视为可生成画面。
- 镜头：5–10 秒内一个主要动作与一个主要运镜；对白与字幕另列。

## 模型输入选择

| 模式 | H3 输入 | 连续性重点 |
| --- | --- | --- |
| `identity_refs` | 人物、服装、场景参考图，合计 1–9 张 | 优先保脸与衣服；预演镜头信息写入提示词，实际空间跟随仍需质检 |
| `first_last` | 首帧，可附尾帧 | 优先控制开始/结束构图；无法同时向当前 H3 流程提交独立人物参考图，必须人工验脸 |
| 灰盒视频参考 | 当前 H3 CLI 未提供此输入 | 只在已验证支持视频参考的其他 provider 接入，不能假装 H3 可用 |

## 质检判据

同一角色逐镜比较脸型特征、发际线、发型、妆容、服装颜色/结构；检查镜头轴、人物站位、道具和场景。实际视频至少看开头、中间和结尾；近景看脸，远景看服装与场景。自动图像相似度只能作为辅助，客户脸部是否一致由人工确认。把具体失败标为 `face_drift`、`wardrobe_drift`、`set_drift`、`camera_drift` 或 `audio_mismatch`，供逐镜重做。
